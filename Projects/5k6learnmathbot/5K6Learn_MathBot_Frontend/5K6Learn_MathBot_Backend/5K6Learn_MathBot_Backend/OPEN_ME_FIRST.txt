5K6LEARN MATHBOT — BACKEND ONLY

REQUIREMENT: Install Python 3.10 or newer (Python 3.11/3.12 recommended). During installation tick “Add Python to PATH”.

1. Extract this ZIP into its own folder.
2. Double-click run.bat. The first launch downloads required Python packages and may take a few minutes.
3. Wait until you see “Backend running at http://127.0.0.1:8000”. Keep this window open.
4. Open the sibling folder `5K6Learn_MathBot_Frontend\5K6Learn_MathBot_Frontend` and double-click `index.html`. Its `app.js` is configured to call this backend at `http://127.0.0.1:8000`.
5. Optional AI explanations for word problems require your own OpenAI API key in this folder’s .env file. Basic symbolic maths does not require a key.

Connection check: open http://127.0.0.1:8000/api/health and confirm it returns `"status":"ok"`.
API docs: http://127.0.0.1:8000/docs
